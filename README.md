# HR Analytics Dashboard using SQL & Power BI

## Project Overview

This project analyzes employee attrition, salary trends, workforce distribution, and demographic insights using SQL and Power BI.

## Tools Used

* MySQL
* Power BI
* Excel

## Dataset

IBM HR Employee Attrition Dataset

## Key Metrics

* Total Employees: 1470
* Attrition Rate: 16.12%
* Average Salary: 6502
* Average Age: 36.92

## Features

* Department Slicer
* Gender Slicer
* Job Role Slicer
* Attrition Analysis
* Salary Analysis
* Workforce Distribution
